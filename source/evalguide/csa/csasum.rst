Summary and Next Steps
======================
This chapter has provided a number of sample applications that aimed to provide you with a better understanding of the OpenClovis SDK. 
To gain further information there are a number of documents you may wish to read. To gain further knowledge on the IDE and create a 
model read the **OpenClovis Modeing Tutorial** or for more in depth information on the SDK read the **OpenClovis SDK User Guide** and 
**OpenClovis API Reference Guide**.
